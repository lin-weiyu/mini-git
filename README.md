# MiniGit

A simplified git implementation written in C++.

## Feature

- init
- add
- commit
- log
- checkout


## Build

### Requirements

- C++17
- CMake >= 3.10

```bash
mkdir build
cd build
cmake ..
make
```

## Usage

### init

```bash
./mini-git init
```

### add

```bash
./mini-git add <file>
```

### commit

```bash
./mini-git commit -m <message>
```

### log

```bash
./mini-git log
```
